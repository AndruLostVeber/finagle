# «Куро Продакшн» — соревнование команд

Каждый участник играет на своем компьютере: личный 3D-кабинет, собственная компания,
самостоятельные бизнес-решения, бухгалтерский журнал и аудит.

## Панель преподавателя и вход учеников

1. Преподаватель открывает `/teacher/`, создает игру и получает код.
2. В панели добавляет команды. Код передает ученикам, ключ преподавателя оставляет себе.
3. Ученики открывают `/`, нажимают «Присоединиться к игре», вводят код существующей игры,
   выбирают команду и указывают имя и компанию. До старта они находятся в лобби.
4. Преподаватель нажимает «Открыть игру · начать». Участники автоматически переходят в личные кабинеты.
5. Панель показывает рейтинг команд и компании участников: прибыль, количество решений,
   время последнего сохранения. Обновление каждые 5 секунд.
6. «Завершить игру» прекращает прием участников и решений; результаты остаются доступными.

Панель сохраняет список созданных игр и доступ в этом браузере. На другом устройстве доступ
восстанавливается по коду и ключу преподавателя. Ключ не передается в ученические ответы API.
Для нового урока преподаватель создает новую игру. Несуществующий код не создает соревнование.
Ученики не могут создавать команды или управлять статусом игры через свой вход.

На компьютере участника: «Бухгалтерия», «Моя компания» с историей решений и
«Результаты команд» с общим рейтингом и компаниями своей команды.

## Прибыль и победа

Игровой прогноз начинается с −250 тыс. ₽. Верная операция добавляет 25 тыс. ₽,
ошибка отнимает 35 тыс. ₽ (потери и исправления). Выбор площадки, финансирования,
оборудования и сырья меняет прогноз; эффект показан перед подтверждением.
Это игровая модель, бухгалтерский результат по счетам считается отдельно в закрытии января.

Рейтинг команды — средняя прибыль ее компаний, поэтому большая команда не получает
автоматического преимущества. При равной прибыли выше команда с большим числом решений.
В соревновании все участники используют единые правила без учебных подсказок.
Финал компании: от 500 тыс. ₽ — успех, от нуля — тяжелый старт, ниже нуля — убыток.
Разговоры с героями меняют настроение.

Прогресс автоматически сохраняется на устройстве; повторное присоединение с тем же кодом возвращает в свою компанию.
Временная потеря сети не удаляет решения: при восстановлении они отправляются в рейтинг.
Для новой партии преподаватель создает новую игру. Текущий демо-квартал содержит
7 дней января; февраль и март пока пропущены.

## Запуск и проверка

```sh
cd deploy/cloudflare
npm ci
npm run build
npm test
npm run dev
```

Игра: http://localhost:8790/. На других компьютерах откройте тот же адрес сервера
в локальной сети или опубликованную версию. Для общего рейтинга все используют один сервер.

`demo-next/index.html` — основной интерфейс. `unity/Assets` — 3D-сцена и мост браузера.
`deploy/cloudflare/src/teams.mjs` — компании и рейтинг; `worker.mjs` — API и долговременное хранение.
Сборка обновляет интерфейс поверх существующего Unity WebGL без повторной компиляции 3D.
Подробнее: [публикация](deploy/cloudflare/README.md).

## Все вопросы

Январь: 33–35 операций (зависит от решений на совещаниях), 4 совещания, 7 разговоров.
- Суммы в тыс. ₽. В столбце «Ответ» — верная проводка.
- У совещаний и разговоров верного ответа нет, в столбце — варианты.
- А, Б, В у операций — выбор на совещании. Оборудование — для набора «все стандарт».
- Технические проводки (НДС к вычету, зачет аванса) игра делает сама.
