# Публикация «Куро Продакшн»

Адрес: https://kuro-production.kuro-cloudflare.workers.dev/

Unity WebGL размещен в Workers Static Assets. Каждое соревнование хранится отдельно
в SQLite Durable Object: команды, личные компании, подтвержденные решения и сохранения.
Приватные ключи компаний не попадают в публичный рейтинг.

## Обновление

```sh
npm ci
npm run build
npm test
npm run deploy
```

Нужна готовая сборка `unity/Builds/WebGL-next`. Сборщик берет свежий интерфейс
`demo-next/index.html` и мост из `unity/Assets/WebGLTemplates/KuroNext/demo/`,
обновляет локальную Unity-сборку, сжимает WASM/данные и готовит `public`.
При изменениях 3D сначала пересоберите Unity через меню Kuro → Собрать WebGL (next).

## Проверка локально

```sh
npm run dev
node test/smoke.mjs
```

Откройте http://localhost:8790/. Smoke-тест использует отдельное тестовое соревнование,
проверяет создание двух команд и трех независимых компаний, решения, рейтинг,
повторную отправку, доступ к сохранению и отсутствие старых маршрутов.
Для проверки опубликованной сборки: `KURO_TEST_URL=https://... node test/smoke.mjs`.

## Панель преподавателя

`/teacher/` — создание игры, команды, открытие старта и завершение, живые результаты.
`/` — ученический вход по выданному коду. Список игр и ключи управления хранятся
в браузере преподавателя. Перенос доступа — по коду и приватному ключу.

## API

- `POST /api/teams/create` — создать игру, получить серверный код и ключ преподавателя.
- `POST /api/teams/teacher` — управление и обзор (ключ преподавателя).
- `GET /api/teams?league=G12AB34CD` — команды и рейтинг, без секретов и личных сохранений.
- `POST /api/teams/join` — присоединиться к существующей команде существующей игры.
- `POST /api/teams/progress` — отправить решения и сохранить состояние (ключ компании).
- `POST /api/teams/resume` — получить свое серверное сохранение (ключ компании).
- `/health` — доступность.

Имена binding `CLASSROOMS` и экспортируемого класса `Classrooms` оставлены только
для совместимости уже опубликованной миграции Cloudflare. Соревнования используют
новые ключи `teams-v2:*`; старые данные не смешиваются с рейтингом.

Модель проверяет допустимые эффекты и однократность решений, но оценка правильности
проводки пока вычисляется клиентом. Для защищенных турниров нужна серверная проверка эталонов.
Секреты и токены Cloudflare не следует добавлять в исходники: авторизацией управляет Wrangler.
